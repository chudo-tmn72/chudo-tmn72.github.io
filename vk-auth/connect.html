Проверка авторизации ВКонтакте

Этот вход проверяет, подходит ли новое приложение VK ID для чтения комментариев сообщества. Лайков не будет.

Коды авторизации и токены останутся внутри браузера. Они не отображаются на странице, не сохраняются на GitHub и не передаются в ChatGPT.

Нажмите кнопку, если хотите проверить доступ.

Никаких платных действий. Не вводите пароль ВК на сайтах, кроме официального id.vk.ru. Проверка использует только базовый доступ, без запроса почты или телефона.
